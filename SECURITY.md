# Security Policy

## Supported versions

Only the latest release of the `chatbase` CLI is supported with security
updates. Run `chatbase --version` and upgrade with `npm install -g chatbase`
before reporting.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately via GitHub's security advisory form:

**https://github.com/Chatbase-co/chatbase-cli/security/advisories/new**

Include what you can: affected command/version, reproduction steps, and
impact. You'll get an acknowledgment within a few business days, and we'll
keep you updated as the fix progresses.

For vulnerabilities in the Chatbase platform itself (the API, dashboard, or
chatbase.co), please refer to https://www.chatbase.co/security instead.
